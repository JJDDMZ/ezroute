# External tools and resources

EZ Route uses Apple system frameworks and the Swift standard library. Package.swift declares no external Swift package dependencies.

Clash Verge Rev and Mihomo are external programs installed separately; their executables, subscriptions, and source are not bundled in this repository. Their licenses apply to those projects:

- Clash Verge Rev: https://github.com/clash-verge-rev/clash-verge-rev
- Mihomo: https://github.com/MetaCubeX/mihomo

The app icon is generated by this project's `script/generate_icon.swift`. JavaScript routing transforms and the domain list are maintained as project source; the domain list contains domain names, without vendored rule datasets.
