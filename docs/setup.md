# EZ Route 使用指南

EZ Route 根据 USB 与 Wi-Fi 的可用状态更新 Clash 出口。手机需要先开启个人热点；Clash Verge Rev 需要开启 TUN。

## 首次配置

1. 运行 `./script/install.sh`，打开 EZ Route。
2. 连接并信任自己的 iPhone，在“设备与热点”中选择设备。
3. 使用无线热点时，连接手机热点，允许读取名称，再登记该热点。
4. 开启“自动路由”，在“概览”核对当前模式。

应用会安装所需的 Clash 全局扩展脚本并保存备份。已有自定义脚本需要先检查兼容性；遇到提示时保留原脚本并检查提示内容。公开版本的学校例外使用示例值，见[校园配置](campus-profile.md)。

## 诊断与监测

连接列表展示目标、策略出口与流量。用量按应用运行期间的接口记录汇总。网站响应检查 HTTP 状态与耗时；实际出口检查在授权后采集测试包头，将接口与测试目标关联。

HTTP 403 或 405 是网站返回的响应，结合实际出口结果判断路由。测试数据只覆盖本轮请求。

## 退出与升级

使用应用菜单中的“退出”，等待路由调整完成。USB 在线时保留手机出口，只有 Wi-Fi 时使用直连，离线时阻断 Clash 请求。无法完成调整时，应用会继续运行并提示处理办法。

安装器会备份旧包。原 bundle identifier 与偏好键保留；首次改名升级后，用“通用”中的“登录时启动”开关重新登记已有登录项。

## 手机切卡

需要双卡自动化时搭配 [EZ SIM](https://github.com/JJDDMZ/ez-sim)。手机快捷指令与 Mac 路由各自运行。
